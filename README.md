# Blog 2: ACME Job Skills

This is the standalone submission and reproducibility repository for Blog 2.

Which specific skills appear most often in ACME job requirements near Philadelphia, and how do mentions differ across job types?

This repository contains the code, data, and results needed to reproduce the analysis. The article is maintained and rendered in the [website repository](https://github.com/annzhao-77/website/blob/main/blog/posts/post2/index.qmd). No Quarto installation is needed here.

- [Tables](results/tables/): job counts, overall skill frequencies, and within-job-type percentages.
- [Figures](results/figures/): the three plots generated by the analysis. The article's ACME logo is a website illustration, not an analysis result.
- [Analysis](code/analyze_acme.R): reads raw data and recreates all clean data, tables, and figures.
- [Scraper](code/scrape_acme.R): optional live collection; not required to reproduce the historical analysis.

## Reproduce the analysis

1. Download or clone this repository and open [BLOG2.Rproj](BLOG2.Rproj) in RStudio. Keep the working directory at the repository root, not inside `code/`.
2. Install packages once, then run the analysis in the R Console:

```r
install.packages(c("dplyr", "stringr", "ggplot2"))
source("code/analyze_acme.R")
```

Tested with R 4.5.3. The included raw CSV is sufficient; an internet connection is not needed after installing packages. The script creates output folders as needed and overwrites generated files when rerun. It leaves raw data unchanged.

Expected results: 118 unique postings and 26 distinct normalized requirements texts. Organization/time management appears in 37 postings (31.4%); communication and attention to detail each appear in 34 (28.8%). The script checks duplicate IDs, the ACME banner, and nonempty requirements.

## Data source and scope

Source: [Albertsons Companies careers — Philadelphia +25 km](https://eofd.fa.us6.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001/jobs?location=Philadelphia%2C+PA%2C+United+States&locationId=300000002802382&locationLevel=city&mode=location&radius=25&radiusUnit=KM).

Collected September 20, 2026. The snapshot contains 118 retrievable ACME postings; the website counter displayed 119. Some returned postings cover regional or multiple locations. The sample reflects search results, not an independently verified geographic boundary.

The nine raw columns are title, job_id, job_category, posting_date, apply_before, job_schedule, locations, banner, and requirements. Missing fields are blank. Some requirements use a Qualifications or equivalent heading.

## Method and interpretation

Job titles are grouped into job types. Requirements are normalized and matched against the 13 skill patterns defined in the script. Each skill counts at most once per posting. Overall percentages use all 118 postings; job-type percentages use the number of postings within that type. Required and preferred mentions are combined. Repeated templates remain in the posting-level analysis.

General customer-service attitudes, age, qualifications, lifting, and availability are excluded from skill rankings. Enjoying a team environment alone is not classified as teamwork. Matching phrases can be inspected in the clean job-skill CSV; the `skill_evidence` object in R contains only matched rows.

The heatmap displays job types with at least five postings. The job-type table retains smaller groups. These are descriptive text mentions, not exhaustive measures of needed skills, skill importance, hiring probabilities, or causal effects.

## Optional: collect new data

Install Google Chrome and the following R packages. Use a version of `rvest` providing `read_html_live()`.

```r
install.packages(c("rvest", "chromote", "stringr", "magrittr"))
source("code/scrape_acme.R")
```

Preserve the historical raw CSV before running: the scraper overwrites `data/raw/acme_jobs.csv` as it collects postings. Live vacancies and page structure change, so this may produce different counts or fail. The scraper accesses public pages, waits between requests, and does not log in, bypass restrictions, or submit applications. Review failed-page messages and missing requirements before analysis. After collecting a new sample, rerun the analysis and revise dates, captions, and narrative to match it.
